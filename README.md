# HistoryIsPower Entertainment website

Static studio site (design **B · Arcade**) at **https://historyispower.com/**, hosted by Hostinger.

- Domain: `historyispower.com`, bought at Hostinger (DNS and email there too). The main address is the bare domain; www forwards to it (`.htaccess`).
- Repo: `HIP-Entertainment/historyispower.com` (public). GitHub Desktop clone at `C:\Users\andre\GitHub\historyispower.com`, outside OneDrive on purpose.
  Hostinger's **Git deployment** pulls `main` into `public_html`, and a GitHub webhook makes it deploy on every push.
- Old address: https://hip-entertainment.github.io/ (repo `HIP-Entertainment.github.io`, clone `C:\Users\andre\GitHub\HIP-Entertainment.github.io`)
  now only holds a forwarding page (`tools\github-pages-redirect\`) that sends every old link to the same page on historyispower.com.
  The separate `Trillionaire-Tycoon-Privacy-Policy` Pages repo isn't affected: the game and the store listings still link there.
- This folder (`Website\`) is the original. Always edit here, never in the clones.

## Updating the site
1. Edit files in `Website\`.
2. If the privacy policy, terms or delete-data page changed: edit the original in `Android\PlayStore\`, then run
   `powershell -ExecutionPolicy Bypass -File Website\tools\build-legal.ps1`
   Also upload the changed file to the `Trillionaire-Tycoon-Privacy-Policy` repo, because the game and the Play listing link there.
3. Run `powershell -ExecutionPolicy Bypass -File Website\tools\publish-site.ps1 -Message "What changed"`
4. In GitHub Desktop pick **historyispower.com** and click **Push origin**. Hostinger deploys it within about a minute.
   If the webhook ever fails: hPanel > Websites > historyispower.com > Advanced > **GIT** > **Deploy**.

The forwarding page only needs publishing again if it changes:
`powershell -ExecutionPolicy Bypass -File Website\tools\publish-site.ps1 -Redirect`, then push **HIP-Entertainment.github.io**.

## Settings (top of `script.js`)
- `web3formsKey`: Web3Forms access key for the contact form. If it's empty, the form opens the visitor's email app instead.
- `cfBeaconToken`: Cloudflare Web Analytics token, for the site `historyispower.com`. If it's empty, no analytics are loaded.
Both are public by design.

## Light and dark mode
- Dark follows the visitor's device setting. The sun/moon button in the menu bar switches by hand, and the choice is saved in the browser as `hip-theme`.
- All colours are tokens at the top of `style.css`. The dark values are written twice there (device setting, and the button choice). Change both blocks together.
- `--ink` stays dark navy in both themes: it's the text on the yellow, green and coral fills. Outlines use `--edge`, normal text uses `--text`.
- Every page has a one-line script in its `<head>` that applies a saved choice before the page draws, so there's no white flash. A new page needs it too: copy it from `index.html`.

## Files
- `index.html`, `style.css`, `script.js`, `favicon.svg`, `images\`: the site.
- `privacy-policy.html`, `terms-of-service.html`, `delete-data.html`: generated by `tools\build-legal.ps1`. Don't edit them here.
- `app-ads.txt`: copied from `Android\app-ads.txt` by build-legal.ps1. AdMob reads it at the root of the store listing's website.
- `404.html`: the "page went bankrupt" page for any missing address (`.htaccess` ErrorDocument). It uses `/`-based links on purpose.
- `.htaccess`: Hostinger server settings (404 page, www to bare domain, hides the deployed `.git` folder, cache times). HTTPS is forced in hPanel.
- `robots.txt`, `sitemap.xml`: search engine helpers. `.nojekyll` is left over from GitHub Pages and is harmless.
- `tools\` and this README are not published.

## Changing the address again
Replace `https://historyispower.com/` in `index.html` (og/canonical), `sitemap.xml`, `robots.txt`, `.htaccess` and
`tools\github-pages-redirect\` (index.html, robots.txt).
